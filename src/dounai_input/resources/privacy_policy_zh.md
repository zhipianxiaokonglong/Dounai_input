# 豆奶输入层声纹功能授权说明

**版本：1.0**

**生效日期：2026-10-24**

## 这段文字解决什么问题

声纹（说话人特征）属于生物特征信息。豆奶输入层只有在取得你的明确同意后，才会为“唤醒词识别”和“陪伴感增强”提取声纹模板。你可以随时关闭功能、撤回同意、删除模板或导出数据。

## 我们处理什么

1. **声纹模板**：从你主动录制的 3–8 段 WAV 语音中提取的数学特征向量。原始录音不会用于声纹存储，也不会写入声纹数据库；上传接口处理完毕后即从内存释放。
2. **唤醒判断结果**：每段音频只会产生 `wakeup` 或 `none` 两种结果，写入标准化事件的 `metadata.voiceprint_event` 字段。
3. **授权记录**：同意/撤回的时间、政策版本。用于证明授权过程，不包含声纹内容。

## 我们不做什么

- 不把声纹模板、声纹相似度或原始声纹样本发送给任何第三方模型厂商。
- 不把声纹用于身份认证、门禁、支付、风控或任何安全决策。
- 不默认开启声纹功能，不在你未同意时进行声纹特征提取。
- 不把声纹模板写入日志、错误信息或遥测数据。

## 数据在哪里

- 声纹模板：仅存于本机 `data/dounai.sqlite3`，目录权限仅当前系统用户可访问。
- 原始上传音频：与普通输入音频一样，按配置的保留期（默认 72 小时）自动删除；用于唤醒判断的 WAV 文件不会额外复制。
- 若你选择远程语音转写模型，音频会发送给你选择的厂商；这是语音转写所必需，与声纹功能相互独立。声纹计算始终在本地先完成或独立完成，模板绝不出设备。

## 你的权利

- **开启 / 关闭**：在 Web 控制台的“隐私”面板或 `PUT /v1/privacy/settings` 关闭。关闭后不再提取声纹，已有模板保留到你删除。
- **撤回同意**：`DELETE /v1/privacy/consent`。撤回会同时删除声纹模板并关闭功能。
- **删除**：`DELETE /v1/privacy/voiceprint` 删除声纹模板；`DELETE /v1/privacy/data?confirm=true` 删除事件、媒体、声纹模板和授权记录。
- **导出**：`GET /v1/privacy/export` 下载 JSON 清单、事件、媒体文件和声纹模板。
- **查看状态**：`GET /v1/privacy/status`。

## 风险与限制

本项目的声纹实现是可解释的 MFCC 统计基线，不是经过大规模说话人验证评测的生产级系统，**不具备抗录音重放、抗合成语音的能力，不能用于安全认证**。环境噪声、麦克风变化、感冒等都可能影响唤醒判断。你可以关闭唤醒词强制匹配，但这样任何已登记声音说话时都可能触发 `wakeup`。

## 同意方式

调用 `POST /v1/privacy/consent`，提交：

```json
{"policy_version": "1.0", "granted": true}
```

或在 Web 控制台勾选“我已阅读并同意上述说明”后点击授权。授权记录会包含时间与政策版本。只有授权、开关开启且已录入模板三个条件同时满足，音频事件才可能出现 `voiceprint_event: "wakeup"`。

如你不同意，请勿授权；输入层仍可正常处理文字、图像和语音，只是不会进行声纹唤醒判断。
